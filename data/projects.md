# Compass starter catalog

This bundled sample lets Compass start without internet access. When online, Compass attempts to load the complete upstream [awesome-open-source-ai](https://github.com/InessaPawson/awesome-open-source-ai) catalog.

## Foundations
### Model Training & Optimization
- [Transformers](https://github.com/huggingface/transformers) - Pretrained model architectures and loading utilities.
- [PyTorch](https://github.com/pytorch/pytorch) - Tensor computation and deep learning.
- [NumPy](https://github.com/numpy/numpy) - Numerical array computing.
### Data & Interactive Development
- [marimo](https://github.com/marimo-team/marimo) - Reactive Python notebooks.
- [Jupyter AI](https://github.com/jupyterlab/jupyter-ai) - AI features for JupyterLab.
## Models & Inference
### Local Inference
- [llama.cpp](https://github.com/ggml-org/llama.cpp) - Lightweight local model inference.
### Model Serving
- [vLLM](https://github.com/vllm-project/vllm) - High-throughput model serving.
## Agents & Orchestration
### Agent Frameworks
- [LangGraph](https://github.com/langchain-ai/langgraph) - Stateful agent orchestration.
- [Pydantic AI](https://github.com/pydantic/pydantic-ai) - Python agent framework.
- [LangChain](https://github.com/langchain-ai/langchain) - LLM application building blocks.
## Retrieval & Knowledge
### Embeddings
- [Sentence Transformers](https://github.com/UKPLab/sentence-transformers) - Text embeddings.
### Vector Databases
- [Chroma](https://github.com/chroma-core/chroma) - Vector database.
- [Qdrant](https://github.com/qdrant/qdrant) - Vector search engine.
## Evaluation & Security
### Evaluation
- [DeepEval](https://github.com/confident-ai/deepeval) - LLM evaluation framework.
- [Ragas](https://github.com/explodinggradients/ragas) - Retrieval-augmented generation evaluation.
### Security Testing
- [LLM Guard](https://github.com/protectai/llm-guard) - LLM input and output scanning.
- [garak](https://github.com/NVIDIA/garak) - LLM vulnerability scanning.
- [PyRIT](https://github.com/Azure/PyRIT) - Generative AI risk testing framework.
## Deployment & Operations
### Serving & Packaging
- [BentoML](https://github.com/bentoml/BentoML) - Model services and deployment.
- [Ray](https://github.com/ray-project/ray) - Distributed compute framework.
