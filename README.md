# Open Source AI Compass

A standalone Python application for discovering open-source AI projects and designing illustrative AI stacks. Built with [Panel](https://panel.holoviz.org/), [HoloViews](https://holoviews.org/), and [Bokeh](https://bokeh.org/).

## Data and project attribution

Open Source AI Compass reads the public source catalog at [https://github.com/openteams-ai/awesome-open-source-ai](https://github.com/openteams-ai/awesome-open-source-ai) when online.

These listings are not security reviews, verified technology integrations, or statements of production readiness. Review upstream licenses, provenance and maintenance status before adoption.
